# 兼容矩阵

本表区分“代码路径存在”和“用真实环境验收”。未提供凭据或运行时的能力不会由 Worker 上报。

| 组件 | 支持范围 | 当前证据 |
|---|---|---|
| Node.js | 22+，pnpm 10 | Windows 原生测试、类型检查和 Web 构建通过 |
| Java | 17+ | Spring Boot/Maven 测试通过 |
| PostgreSQL | PostgreSQL 14+ | Windows 原生迁移、读写、逻辑备份/隔离恢复通过 |
| S3/MinIO | S3 v4 API | Windows MinIO 写入、镜像备份/隔离恢复通过 |
| Windows | PowerShell 7 原生开发栈 | 已验收 |
| Linux | Docker/Compose 或原生依赖 | 构建文件存在；本机未验收 |
| macOS | 原生 Node/Java + 外部 PostgreSQL/S3 | 未验收 |
| Docker Compose | Compose v2.24+ | 配置存在；当前主机无 Docker，未验收 |
| Kubernetes | Helm 3 + NetworkPolicy/PDB/探针 | Chart 存在；当前主机无 kubectl/集群，未验收 |
| Gateway | 单 Gateway，多 Agent | 派发、幂等、断线和自动重连有测试；多 Gateway 不支持 |

## 数据平台目录

| 平台/来源 | 获取路径 | 状态与边界 |
|---|---|---|
| Bluesky | Jetstream 开放协议 | 真实匿名增量流；不提供匿名历史检索 |
| Reddit | 官方 OAuth API | 帖子/评论树实现与离线测试通过；真实凭据未验收 |
| YouTube | Data API v3 | 视频/评论实现与离线测试通过；真实 key 未验收 |
| RSS / REST / Web | 受 SSRF/robots 约束的只读 GET | 游标、失败恢复有测试；当前主机 DNS 代理阻断真实 RSS/Web 验收 |
| 小红书 | Spider_XHS，自有账号 | 外部可选适配器；未用真实账号验收 |
| 小红书/抖音/TikTok | TikHub | 供应商适配器；未用真实 key 验收 |
| Creator-owned | `fetchOwned` Provider contract | 认证 API、`owned:fetch` scope、密文授权句柄和审计已实现；需实现并注册真实授权 Provider |
| GEO | 匿名 CDP 官网观测 | SSRF/robots/Trace 实现；当前无 CDP，未做真实会话验收 |
| OpenCLI | 1.8.5 动态只读目录 | 当前扫描 1,257 条命令，其中 316 条/79 个站点可在无 CDP 时调度；浏览器命令需真实 Profile/CDP |
| Dify | workflow/advanced-chat DSL 安全导入 | start/LLM/answer 等映射；code/tool/plugin/agent/loop 默认阻断，未配置强隔离沙箱 |

明确排除：会话 Cookie 注入 ThreadBeacon HTTP 客户端、平台签名逆向、任意 JavaScript/eval、DRM 绕过、OpenCLI 写操作/下载/任意输出路径、匿名全站抓取中国平台。目录出现某平台不代表平台授权或商业使用许可。
