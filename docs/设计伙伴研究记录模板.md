| 来源可行性 |  |  |
| 有明确受众和决策 |  |  |
| 试点承诺强度 |  |  |
| **总分 / 16** |  |  |

判断：

- `13-16`：优先设计伙伴候选。
- `9-12`：保留观察，确认最弱证据。
- `0-8`：不是当前 ICP，记录替代场景即可。
